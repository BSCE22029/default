Pipeline snapshot
What's real here, and what is not
  • Real: pattern-based intent classification with negation handling (“not interested” is not “interested”), entity extraction (emails, phone numbers, dates such as “back on 12 December”, timeframes such as “in 3 weeks”, names after “speak to”), response drafting, and live changes to the shared pipeline and do-not-contact list. A live time-zone lookup lets it propose meeting slots in the prospect's local time.
  • Compliance by design: “unsubscribe”, “stop”, and even a bare “no” (which the BD agent's opt-out line promises to honour) put the prospect on the do-not-contact list so no further message can be drafted.
  • Not an LLM: it is a rule set I wrote, so it does well on typical replies and says “needs a human” when it is unsure or the message mixes intents. I tested it on the 10 samples below, which I wrote to cover the common cases, not on a large real inbox. Always read a reply yourself before you send a response.
