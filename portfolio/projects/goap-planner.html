What's real here
  • The planner is real search. Every state is (location, set of items). Actions have preconditions, effects and costs, like STRIPS or the GOAP used in game AI. Uniform-cost search finds the cheapest sequence, and the “states searched” counter is the actual number of states it expanded.
  • Sensing and replanning are real. Before each step the agent checks that the action still works in the current world. If not (no axe, road closed, forge on fire) it searches again from where it stands. If no plan exists, for example the forge is burning and the goal needs a sword, it says so instead of looping forever.
  • The world is small and fully known to the agent, with no randomness. It is a planning demo, not a learning one: nothing here is trained.
