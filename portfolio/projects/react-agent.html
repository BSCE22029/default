What's real here, and what is not
  • Real: the agent loop (a JavaScript generator that yields Thought, Action and Observation events), a tool registry with four tools (search, calculator, convert, memory), a safe expression parser written by hand (no eval), a TF-IDF fact search, spell-correction retry when confidence is low, error handling, and a stop condition.
  • Not an LLM: the “reasoning” that decides which tool to call is a deterministic rule-based planner I wrote, standing in for the model. In a production agent a language model would emit the Thought and Action; the loop, tools, memory and error handling around it would look the same. So it only understands questions its parser can read, and it says so instead of guessing.
  • The knowledge base is 38 hand-entered facts with approximate figures (populations, heights). Ask about something outside it, like the population of Atlantis, and the agent refuses rather than inventing an answer.
