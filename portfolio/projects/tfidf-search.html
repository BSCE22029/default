TF-IDF Search Engine

Every document becomes a vector; your query becomes one too; the closest vectors win. Search a small AI knowledge base and see your query land on a 2-D map computed with real PCA.

What's real here
  • Each document is turned into a vector of (1 + log tf) × idf weights and length-normalised. Ranking is cosine similarity between the query vector and every document. Rare words weigh more than common ones.
  • The map uses real PCA: the vectors are centred, the top two principal components are found with power iteration, and the query is projected into the same space.
  • Honest limits: this is lexical matching on 30 short documents I wrote, with light suffix stemming. It does not understand meaning the way neural embeddings do, so a query with no overlapping words finds nothing. That gap is exactly why modern search adds embeddings.
