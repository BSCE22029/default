What's real here
  • Weights are initialised with Xavier scaling and trained with mini-batch gradient descent (batch size 10) on a 70/30 train/test split.
  • The output neuron is a sigmoid trained with binary cross-entropy; the gradients are derived by hand and applied layer by layer. No ML library is used.
  • Try the spiral with only x and y as inputs: a small network struggles. Add the sin(x), sin(y) features or more neurons and watch the boundary snap into place. Too many neurons on noisy data shows overfitting as test loss rising above train loss.
