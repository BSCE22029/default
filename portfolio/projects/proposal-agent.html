What's real here, and what is not
  • Real: the agent parses your pasted text (budget, timeline, required vs nice-to-have skills using a skill dictionary of about 70 technologies with aliases), compares it with the skills you list, scores the fit, applies red-flag rules (unpaid trials, off-platform payment, absurd deadlines, budget far below the estimated work) and builds the effort estimate from deliverable keywords. All of it runs in your browser and nothing is uploaded.
  • Honest by design: any required skill you did not list is named in the proposal as a gap, with how you would handle it. It never claims a skill you did not enter. Related skills (for example Vue when you know React) are shown as “adjacent”, not as a match.
  • Not an LLM: the proposal is assembled from templates and the specifics found in the post, so read it and add your own voice. The hours are rough rule-of-thumb figures, not a quote: check them against your own experience.
