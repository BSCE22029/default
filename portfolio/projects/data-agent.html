What's real here, and what is not
  • Real: every number comes from a live HTTP request made by your browser to a public API: Open-Meteo (geocoding and weather), ExchangeRate-API (rates), Wikipedia, Hacker News and GitHub. Nothing is mocked or cached on my side. Results change as the world changes.
  • Real agent behaviour: the agent picks tools, chains them (find the city's coordinates, then fetch its weather, then read its local time), caches repeated calls within the session, retries a failed request once, and reports honestly when an API is down or a place is not found.
  • Not an LLM: the part that reads your question and chooses tools is a set of rules I wrote, so it understands weather, time, currency, Wikipedia lookups, Hacker News and GitHub repo questions, and nothing else. In a production agent, a language model would make that choice and these same tools would run underneath.
  • Free public APIs have rate limits (GitHub allows 60 requests an hour per IP). If one is busy the agent will say so.
