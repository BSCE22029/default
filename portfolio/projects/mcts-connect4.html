What's real here
  • Real search: the agent grows a game tree with UCT (Upper Confidence bounds for Trees): it selects a promising node, expands it, plays the game out with random moves, and passes the result back up. The table on the right is the real visit and win counts from that search, not an animation.
  • No game knowledge beyond the rules. It is never told to block a three-in-a-row; it finds blocks because losing branches show up in its simulations. With a very small budget (50) it misses things, and you can beat it. With thousands it rarely loses a tactic.
  • Not a solved game: Connect Four can be solved perfectly with deep search and a strong evaluation. This is the same family of method as the planning inside AlphaGo, minus the neural network, so it is strong but not perfect.
